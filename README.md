# Cuckoo — 悬浮翻译（安卓原生应用）

中英互译即时翻译 App，带悬浮球。**只做手动模式：复制一段话，点悬浮球，马上翻译，再复制译文粘贴回去。**

**这不是网页版。** 原生 Android 应用（Kotlin，纯原生 Views，minSdk 26，targetSdk 34），需要安装到真机并手动授权悬浮窗权限才能用悬浮球。

## v1.6.2 的变化（2026-11-10，根治 v1.6.0 的 workaround，未打包）

**用户反馈：面板里不能自己输入翻译内容，读剪贴板也读不到，还要切回主页面输入，多此一举，悬浮球失去了方便的意义。** 用户说得对，v1.6 把输入框拿掉是治标不治本。

**根因**：面板是 `TYPE_APPLICATION_OVERLAY` + `FLAG_NOT_FOCUSABLE` 的悬浮窗，v1.6 把 EditText 整个拿掉了，所以没法打字；剪贴板也读不到——Android 10+ 只允许获得焦点的应用读剪贴板，面板永远不聚焦、读剪贴板的代码还在 Service 里跑，系统直接返回空。不是用户没复制，是代码拿不到。

**根治（换架构）**：面板改成真正的半透明 Activity（`TranslatePanelActivity`，对话框式小卡片），悬浮球仍是悬浮窗。Activity 是真正获得焦点的窗口，输入法、返回手势、剪贴板读取全部走系统标准行为：面板里恢复了 EditText，点球进来直接打字；`onResume` 时读剪贴板（此时有焦点，Android 10+ 允许），复制完点球自动填入并翻译；键盘开着时返回先收键盘，再返回关闭面板回到聊天；点面板外面也可关闭。`FloatingBallService` 只留悬浮球 + 前台通知，悬浮窗面板那套代码全部删除。SessionStore 会话持久化、12 意图 + LLM 回复建议保留；不加回无障碍权限，权限保持 7 个。面板位置固定在屏幕上方（Activity 窗口不支持悬浮窗式拖动）。

**按用户新规则暂不打包**：只改了架构和预览图（预览在 `workspace/your_files/floating-translate-preview-v16/`），没有打新的 APK，等用户看了预览满意了再打 v1.6.2。

## v1.6.0 的变化（2026-11-10）

**先说技术真相（用户问：悬浮框和输入法是不是底层同一层、必须一起退出？）**
不是同一层。悬浮框是 `TYPE_APPLICATION_OVERLAY` 窗口，输入法是系统输入法窗口，两个独立窗口。但 Android 的返回分发会把它们绑在一起：悬浮窗平时 `FLAG_NOT_FOCUSABLE` 根本收不到返回；点输入框后变可聚焦，输入法先吃掉返回；三星/华为手势返回还会在键盘收起后补发一个返回；`onKeyPreIme` 在真机手势返回上不可靠。所以 v1.4/v1.5 两版“两步返回”代码里看着对、真机上还是失效——不是写错一行，是架构选错了：在悬浮窗里放可编辑输入框，本身就是 Android 上最难做对的形态，Google 翻译气泡、LoloTrans 都不在气泡里放输入框。

**根治（换架构，不再修 flag）**：面板里的输入框整个拿掉，面板永远 `FLAG_NOT_FOCUSABLE`，绝不抢焦点，永远不弹输入法。面板只做三件事：显示剪贴板自动填入的原文（只读）、翻译按钮、译文 + 复制按钮 + 折叠的回复建议。想改文字、想打字，点面板里的“去主界面输入”进 Cuckoo 主界面（正常 Activity，输入法和返回都是系统标准行为）。面板不存在“收键盘也收面板”的问题：返回手势回到聊天，面板不受影响；收面板只靠 × 按钮或点面板外。`BackAwareEditText` 已删除。SessionStore 会话持久化保留，面板重开恢复上次译文。

**图标重设计（更卡通）**：布谷鸟改卡通——圆滚滚的青绿色鸟身、白色大肚子、两只大眼睛（白眼珠 + 黑眼珠）、黄色小尖嘴、头顶一小撮毛、圆弧翅膀、两只黄色小脚；鸟嘴前一个圆润对话气泡，气泡里是青绿色字母 A。颜色：青绿 #14B8A6 / 深青 #0F766E + 黄色 #FBBF24 + 白底，活泼卡通，不要写实剪影、不要深灰严肃风，无渐变。双层自适应图标（前景 + 背景各 108×108dp，图案在中间 66×66dp 安全区内）+ 各密度 PNG fallback 齐全。悬浮球同步换成卡通小鸟头迷你版：40dp 白球里一只卡通小鸟头，不再用“译”字大字。通知 smallIcon 继续用白色镂空版。

## v1.5.0 的变化（2026-11-10）

- **改名 Cuckoo**：App 名字改成 Cuckoo（布谷鸟），主界面标题、通知标题同步改名，副标题保留“悬浮翻译”说明。
- **图标重做（布谷鸟 + 翻译）**：启动图标是简约风的布谷鸟侧影——深灰鸟身 + 青色翅膀弧线，鸟嘴前一个小对话气泡，气泡里是青色字母 A（A 代表语言互译，气泡代表对话，鸟代表 Cuckoo）。只用深灰 + 青色 + 白底 3 色，无渐变、无复杂插画。双层自适应图标（前景 + 背景各 108×108dp，图案在中间 66×66dp 安全区内）+ 各密度 PNG fallback 齐全。悬浮球也同步换成小鸟迷你版：40dp 白球中间一只小布谷鸟剪影，不再用“译”字大字。
- **返回手势根因重查重修**：v1.4.0 只靠面板根布局 dispatchKeyEvent 拦截返回键，但悬浮窗平时 FLAG_NOT_FOCUSABLE 根本收不到按键；输入法先吃 BACK，手维护的标志位又和真实输入法状态脱节，手势返回补发的第二个 BACK 就把面板关了。改成标准解法：输入框重写 onKeyPreIme，在输入法之前拦截 BACK，键盘开着时一次返回只收键盘并消费掉，绝不传到面板；键盘可见状态改由布局监听实测（可见区域高度差），收键盘后延迟 150ms 再恢复 NOT_FOCUSABLE，让进行中的手势先结束；dispatchKeyEvent 只留作第二层兜底。
- **翻译内容不再丢失**：面板收起只是隐藏视图，数据不销毁。会话（原文 + 译文 + 方向 + 建议 + 来源 + 意图）存内存 + SharedPreferences，再点球进来立刻恢复上次内容，不重新联网；只有复制了新的不同内容或点“清空记录”才更新；没点翻译就收起的输入文字也当草稿存下来。
- **建议回复更智能**：本地规则重写为 12 种意图（问候、问时间、问价格、问地点、问选择、一般提问、感谢、道歉、确认、邀请、告别、陈述）+ 时间/价格/地点实体抽取，回复贴合原文、口语化。主界面新增“智能回复（可选）”：填 OpenAI 兼容大模型接口和 Key 后，面板优先走大模型智能生成，失败自动降级本地规则，标题注明是“智能生成”还是“本地规则”以及识别出的意图。

## 功能

- **悬浮球**：40dp 小白球，中间一只卡通小鸟头（青绿圆头 + 大眼睛 + 黄色小尖嘴），可拖动、贴边吸附、拖到底部关闭；点一下展开小面板，双击翻译剪贴板。
- **不锁死聊天页面**：悬浮球永不抢焦点；翻译面板只包内容，面板外触摸直接落到聊天 App 上；点面板外任意处、右上角 × 都能收起。
- **即时翻译，引擎可自选**：主界面“翻译引擎”里可自己选——Google 免费、MyMemory 免费、DeepL（填你自己的 Key）、自定义接口（填地址和 Key），带测试按钮，失败时明确提示换引擎。默认仍是免费接口（Google 免费端点，失败自动降级 MyMemory）。
- **回复建议（语言逻辑）**：对方发什么语言，回复建议就用什么语言，每条下面附另一语言的翻译对照。对方发英文 → 建议回复是英文，每条下面附中文翻译；对方发中文 → 建议回复是中文，每条下面附英文翻译。点“复制回复”复制对方语言的回复，点“复制翻译”复制对照翻译。面板里默认折叠，点一下展开；标题注明是“智能生成”还是“本地规则”以及识别出的意图。本地规则是 12 种意图 + 实体抽取；主界面“智能回复”里填了大模型 Key 后优先走 LLM 生成，失败自动降级。
- **主界面**：手动翻译、悬浮球开关 + 悬浮窗权限、翻译方向、悬浮球大小（32–56dp）/ 透明度、翻译引擎选择、使用说明。打开 App 就能用手动翻译，不用开任何权限。

## 安装到安卓手机

1. 手机：设置 → 安全 → 允许安装未知来源应用（或在安装 APK 时按提示允许本次安装）。
2. 把 APK 传到手机，点 APK 安装。**务必先卸载旧版再装 v1.6.2，不要覆盖安装。**
3. 打开 App「Cuckoo」。App 启动不需要任何权限：不自动拉起悬浮球服务，打开就能先用手动翻译。

## 唯一要开的权限：悬浮窗

App 内点「去开悬浮窗权限」，或手动：设置 → 应用 → Cuckoo → 悬浮窗 / 在其他应用的上层显示 → 允许。
华为路径参考：设置 → 应用和服务 → 应用管理 → Cuckoo → 权限 → 悬浮窗 → 允许（不同系统版本菜单名略有差异，以实际为准）。

开完后打开悬浮球总开关，屏幕上出现 40dp 小白球，通知栏出现“Cuckoo”的通知，点通知回主界面，点“关闭悬浮球”可关掉。

## 测试流程

1. 在微信 / WhatsApp 里复制一段话（例如对方发 "How are you doing today?" 或 "你好，最近怎么样？"）。
2. 点悬浮球，剪贴板内容自动填入小面板，点“翻译”，应显示译文。
3. 点“复制译文”，粘贴回聊天框，应是译文。
4. 点“回复建议 · 点开”展开，检查语言：对方发英文时，建议回复应是英文，每条下面附中文翻译；对方发中文时反过来。
5. 点面板外任意处、右上角 ×，面板应收起；再点悬浮球，面板应重新展开。
6. 面板里没有输入框，永远不弹输入法：做返回手势应直接回到聊天，面板不受影响；点 × 或面板外收起面板。想自己打字，点面板里的“去主界面输入”，在主界面输入框里打字翻译。面板收起后，再点球进来应直接看到上次的译文和建议，不用重新翻译。
7. 拖动悬浮球到屏幕另一侧，松手应贴边吸附；拖到底部边缘松手，悬浮球应关闭。
8. 切换语言方向、切换翻译引擎（例如切到 MyMemory），点“测试引擎”，看是否通过。
9. 断网测试：关掉 Wi-Fi 和流量，点翻译，应出现“翻译失败：请检查网络后重试”而不是闪退。
10. 启动测试：不给任何权限直接打开 App，应正常进入主界面，手动翻译可用，不闪退、不白屏。

## 已知限制

- **不读屏幕**：v1.4.0 已砍掉无障碍自动识别，只做复制翻译；想翻哪句就复制哪句。
- **翻译依赖网络**：免费端点在国内网络下可能不可用，失败时会自动降级到 MyMemory；两个都不可用时会提示失败，不会假装翻译成功。DeepL 和自定义接口需要你自己的 Key。
- **悬浮球保活**：系统省电 / 后台清理可能杀掉前台 Service，悬浮球消失后回 App 重新打开总开关即可；华为/三星手机建议在电池优化里把本 App 设为不优化 / 允许后台运行。

## 在 Android Studio 里打开、编译出 APK

1. 安装 Android Studio（Hedgehog 或更新版，含 Android SDK 34、JDK 17）。
2. 打开 Android Studio → Open → 选择本项目文件夹 `floating-translate-android`。
3. 等 Gradle 同步完成（首次需要联网下载依赖）。
4. 菜单 Build → Build App Bundle(s) / APK(s) → Build APK(s)。
